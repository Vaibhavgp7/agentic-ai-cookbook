# invoice-utils

Demo Python package for the LangChain **Shell Tool Middleware** lab.

Built and tested with [uv](https://docs.astral.sh/uv/).

## Quick commands

```bash
uv sync --extra dev    # install deps + editable package
uv run pytest -v       # run tests
uv build               # build wheel + sdist into dist/
bash scripts/deploy.sh # simulated staging deploy
```
