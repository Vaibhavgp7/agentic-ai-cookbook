1. Why Summarization Middleware?

Long conversations inflate token usage, slow responses, and can degrade model quality. Trimming drops old messages entirely; summarization compresses older turns into a short summary so the agent keeps high‑level context without storing every raw message.

LangChain’s SummarizationMiddleware runs when message count crosses a threshold, summarizes older content with a model, and keeps a configurable number of recent messages verbatim—ideal for production agents with long threads.

DB_PATH = "summarize_middleware_demo.db"

def create_demo_database(path: str = DB_PATH) -> None:
    conn = sqlite3.connect(path)
    cur = conn.cursor()
    cur.execute("DROP TABLE IF EXISTS orders")
    cur.execute("""
        CREATE TABLE orders (
            id INTEGER PRIMARY KEY,
            customer_name TEXT NOT NULL,
            sku TEXT,
            status TEXT,
            tracking TEXT
        )
    """)
    rows = [
        (12345, "John Doe", "WIDGET-A", "shipped", "TRK123456"),
        (12346, "John Doe", "WIDGET-B", "delivered", "TRK123457"),
        (12347, "Jane Smith", "GADGET-1", "processing", None),
        (12348, "Jane Smith", "GADGET-2", "shipped", "TRK123458"),
    ]
    cur.executemany(
        "INSERT INTO orders (id, customer_name, sku, status, tracking) VALUES (?, ?, ?, ?, ?)",
        rows,
    )
    conn.commit()
    conn.close()
    print(f"Demo DB ready: {path}")

create_demo_database()

model = ChatOpenAI(model="gpt-4.1-mini", temperature=0)
db = SQLDatabase.from_uri(f"sqlite:///{DB_PATH}")

3.2 Conversation Simulator (sizes only)

Your Task

Create a new cell, paste or type the code below, and run it to define the simulator used in the next section. 

def _msg_chars(msg) -> int:
    c = msg.content
    if isinstance(c, str):
        return len(c)
    return len(str(c))


def _print_message_sizes(messages, label: str) -> None:
    total_chars = sum(_msg_chars(m) for m in messages)
    print(f"  {label}: {len(messages)} messages, {total_chars} total chars")
    for idx, msg in enumerate(messages):
        print(f"    [{idx}] type={msg.type} chars={_msg_chars(msg)}")


def simulate_conversation(agent, config, messages_list, title="Conversation"):
    """Run turns and print counts/sizes only (no full message bodies)."""
    print(f"\n🗣️ {title}")
    print("=" * 60)

    for i, message in enumerate(messages_list):
        response = agent.invoke(
            {"messages": [{"role": "user", "content": message}]},
            config,
        )
        msgs = response["messages"]
        last = msgs[-1]
        print(f"\n— Turn {i + 1}/{len(messages_list)} —")
        print(f"  user prompt chars: {len(message)}")
        print(f"  last message type: {last.type}, chars: {_msg_chars(last)}")
        _print_message_sizes(msgs, "checkpoint messages")

4. Summarization Middleware

SummarizationMiddleware triggers when the message list reaches a size you configure (here: every 10 messages), keeps the latest messages verbatim (here: 4), and summarizes the rest with a lightweight model. The main agent still sees prior context via the summary, without holding every old message.

4.1 Create a Summarization-Enabled Agent

Your Task

Create a new cell, paste or type the code below, and run it to build the agent with SummarizationMiddleware. 

# Agent with summarization middleware (same model instance as the SQL toolkit)
summarize_agent = create_agent(
    model=model,
    tools=tools,
    system_prompt="""You are a helpful assistant with:
    - SQL tools: answer questions about the local SQLite database (orders table). Use read-only SELECT queries; use the toolkit to list tables/schema before querying.
    - Web search: use tavily_search for public, up-to-date facts (shipping carriers, industry news) when the database is not enough.

    Be concise. If you see a conversation summary, use it for continuity across turns.""",
    middleware=[
        SummarizationMiddleware(
            model=ChatOpenAI(model="gpt-4.1-mini"),
            trigger=("messages", 10),
            keep=("messages", 4),
        )
    ],
    checkpointer=InMemorySaver(),
)

print("📝 Summarization-enabled agent created (SQL toolkit + Tavily search)!")
print("🧠 This agent will summarize old messages when the trigger threshold is reached.")
print("⚙️ Settings: trigger every 10 messages, keep last 4 messages verbatim")

4.3 Visualizing the Summarization Pattern

Unlike hard trimming, summarization keeps important earlier information in compressed form: a summary plus recent turns stays within limits while preserving more nuance than dropping old messages entirely. Your simulator output shows how many messages remain and how large they are—enough to verify summarization without pasting full text. 

Summarization Pattern in Action:

Before Summarization (12 messages):       After Summarization (9 messages):
┌─────────────────────────┐               ┌─────────────────────────┐
│ [System] You are...     │ ──────────────→│ [System] You are...     │
│ [Human] Hi, I'm John    │ ┐              │                         │

│ [Human] Look up info    │ │ SUMMARIZED   │ [AI] 📝 SUMMARY:        │

│ [AI] Order #12345...    │ ┘              │ issues with order       │
│ [Human] Address update  │ ──────────────→│ #12345 delivery delay   │
│ [AI] Address updated    │ ──────────────→│ and updated address to  │

Benefits:
✅ Preserves important context
✅ Manages memory efficiently
✅ Smaller footprint than full history

Considerations:
⚠️ Extra API calls for the summarizer model
⚠️ Summary quality depends on the summarization model and prompt
