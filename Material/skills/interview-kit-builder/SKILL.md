# Interview Kit Builder

Prepare consistent, non-discriminatory interviews for shortlisted candidates.

## Inputs required

1. Approved job description
2. Screening notes (gaps and clarification themes)
3. Interview stage: recruiter screen / technical / hiring-manager

## Steps

1. Extract must-have and good-to-have competencies from the JD.
2. Map each competency using `competency-framework.md`.
3. For each screening gap, draft 1–2 targeted clarification questions.
4. Draft questions using rules in `question-bank-guide.md`.
5. Produce the kit in the output format below.

## Output format

### Interview Kit — [Role Title] — [Stage]

**Competencies to assess** — table: competency | why it matters | suggested depth

**Recommended questions (6–10)** — each with: question, what good looks like, red flags (skill gaps only)

**Follow-ups from screening notes**

**Questions to avoid for this role**

**Interviewer reminders**

Output is a DRAFT for the hiring manager to approve.
