# Competency Framework — Technical hiring

| Competency | Assess via | Strong signal | Weak signal |
|------------|------------|---------------|-------------|
| Java / Spring Boot | Project walk-through | Describes modules owned, API design | Keyword only on resume |
| REST APIs | Design discussion | Verbs, errors, integration | Consumed APIs only |
| React | Scope question | Built components, state | "Basic exposure" with no example |
| SQL | Practical scenario | Queries, indexes at high level | ORM-only |
| Telecom domain | Domain story | OSS/BSS, billing context | Generic IT only |

Weight must-have competencies heavier in question count.
