The story, in plain words

You are the claims officer (the human at the keyboard). The crew has already written a preliminary opinion (a first reading) and a brief (a short note) for the hard file, CLM-20481. Both notes are non-binding (they do not force a payment). A senior examiner (a more senior human who is not in this chat) is still the only person who can pay or refuse. Someone in the chat still has to say what happens to that note.

A human in the loop (a pause where a person chooses the next step) is that moment. The person is you. The pause belongs on one door only. A rules check for CLM-10021 is finished when the sentence is written. A missing police report on CLM-10044 is finished when the desk asks for the paper. Neither of those needs a second decision from you. CLM-20481 does.

You get three choices, and none of them pays the claim.

Why the pause is a button, not a prompt in the terminal

CrewAI can pause inside a flow. Two tools do it.

@human_feedback sits on a flow method. When that method returns, the flow stops and asks a person to type. You can give it emit, a list of labels such as approved and rejected. A model then reads the typed sentence and picks one of those labels, and the matching @listen runs. The latest reply is kept on last_human_feedback. The history of replies is human_feedback_history.

Flow.ask is the smaller version: the method calls self.ask("...") and waits for a typed answer.

Both use a provider. If you do not set one, the provider is the console. It blocks the Python process on input until someone types in the terminal that started the program. Streamlit is that process. The browser is not the terminal. If the flow called input, the page would spin, the terminal would be the only place a person could answer, and a claims officer looking at the chat would have nothing to click.

There is a task flag, human_input, that does the same kind of terminal pause in the middle of a crew. Do not turn it on. The claims officer is in the browser.

So the pause lives in the page. Streamlit (the library that draws the chat) runs the script from the top on every click. Anything you want to remember has to sit in st.session_state (the page's memory, which survives a click; an ordinary Python variable does not). We remember three things: whether a decision is waiting, which claim it belongs to, and the question you asked, so Send back can repeat it. The flag is set only when the answer starts with DESK ROUTE: ask_the_crew. That line is how the page knows the crew ran. The rules door and the papers door do not set the flag, so they do not show the buttons.

The flow is not changed. desk_flow.py still returns as soon as the brief is written. It does not know about the buttons. The page reads the answer, and if the door was the crew, the page waits. Sending the file back calls respond again, which starts a new flow and, for this claim, the crew. That is a second turn, not a pause inside kickoff.

Replace app.py

This is the whole page. The caption, the decision flags, the three buttons, and the Desk decision: lines are the new parts. The sidebar and the call to respond stay. Search the terminal for Desk decision:. Accept and Change amount must not be followed by Crew start:. Send back must be.

import streamlit as st

from desk import respond
from sample_claims import CLAIM_ORDER, CLAIMS

st.set_page_config(page_title="Suraksha Claims Desk", layout="centered")
st.title("Suraksha Claims Desk")
st.caption("The desk chooses a door. The crew runs only for a complex file. You decide what happens to that note.")

if "messages" not in st.session_state:
    st.session_state.messages = []
if "active_claim" not in st.session_state:
    st.session_state.active_claim = CLAIM_ORDER[0]
if "pending_prompt" not in st.session_state:
    st.session_state.pending_prompt = None
if "show_decision" not in st.session_state:
    st.session_state.show_decision = False
if "decision_claim" not in st.session_state:
    st.session_state.decision_claim = None
if "last_question" not in st.session_state:
    st.session_state.last_question = ""

with st.sidebar:
    st.header("Claim file")
    claim_id = st.radio(
        "Select a claim",
        CLAIM_ORDER,
        format_func=lambda cid: f"{cid} — {CLAIMS[cid]['title']}",
    )
    st.markdown(CLAIMS[claim_id]["narrative"])
    st.divider()
    st.subheader("Try these")
    for prompt in (
        "Is this loss covered?",
        "What is the chassis number?",
        "Should we pay this claim now?",
    ):
        if st.button(prompt, use_container_width=True):
            st.session_state.pending_prompt = prompt

if st.session_state.active_claim != claim_id:
    print(
        f"Desk decision: left {st.session_state.active_claim} for {claim_id}. Buttons cleared.",
        flush=True,
    )
    st.session_state.messages = []
    st.session_state.active_claim = claim_id
    st.session_state.show_decision = False
    st.session_state.decision_claim = None

for message in st.session_state.messages:
    with st.chat_message(message["role"]):
        st.markdown(message["content"])

typed = st.chat_input("Ask about the selected claim")
user_text = st.session_state.pending_prompt or typed
if st.session_state.pending_prompt:
    st.session_state.pending_prompt = None

if user_text:
    print(
        f"Desk decision: question on {claim_id}. {user_text}",
        flush=True,
    )
    st.session_state.last_question = user_text
    st.session_state.messages.append({"role": "user", "content": user_text})
    with st.chat_message("user"):
        st.markdown(user_text)
    with st.chat_message("assistant"):
        with st.spinner("The desk is choosing a door..."):
            try:
                answer = respond(user_text, CLAIMS[claim_id])
            except Exception as exc:
                print(
                    f"Desk decision: {claim_id} failed before a note. {exc}",
                    flush=True,
                )
                answer = f"The desk could not finish.\n\n{exc}"
        st.markdown(answer)
    st.session_state.messages.append({"role": "assistant", "content": answer})
    waiting = answer.startswith("DESK ROUTE: ask_the_crew")
    st.session_state.show_decision = waiting
    st.session_state.decision_claim = claim_id if waiting else None
    if waiting:
        print(
            f"Desk decision: {claim_id} is waiting. Three buttons. Not a payment.",
            flush=True,
        )
    else:
        print(
            f"Desk decision: {claim_id} finished on this door. No buttons.",
            flush=True,
        )

if st.session_state.show_decision and st.session_state.decision_claim == claim_id:
    st.divider()
    st.markdown("**The note is non-binding. Choose what the desk should do with it.**")
    accept, change, send_back = st.columns(3)
    accepted = accept.button("Accept for the examiner", use_container_width=True)
    changed = change.button("Change amount", use_container_width=True)
    sent_back = send_back.button("Send back", use_container_width=True)
    amount = st.number_input(
        "Figure to put in the note, in INR",
        min_value=0,
        value=0,
        step=1000,
        key="note_amount",
    )

    if accepted:
        print(
            f"Desk decision: accept {claim_id}. No crew. Not a payment.",
            flush=True,
        )
        note = (
            "ACCEPTED FOR THE SENIOR EXAMINER — NOT A PAYMENT\n\n"
            f"The claims officer accepts the preliminary note on {claim_id} "
            "and sends the file on. No money has moved. The senior examiner still decides."
        )
        st.session_state.messages.append({"role": "assistant", "content": note})
        st.session_state.show_decision = False
        st.rerun()

    if changed:
        if int(amount) <= 0:
            print(
                f"Desk decision: change amount refused for {claim_id}. Figure was {int(amount)}.",
                flush=True,
            )
            st.warning("Type a figure greater than zero, then press Change amount.")
        else:
            print(
                f"Desk decision: amount in the note for {claim_id} set to INR {int(amount)}. Database unchanged. No crew.",
                flush=True,
            )
            note = (
                "AMOUNT CHANGED IN THE NOTE — NOT A PAYMENT\n\n"
                f"The claims officer sets the figure in the note on {claim_id} to INR {int(amount)}. "
                "The database estimate is unchanged. The crew did not approve this figure. "
                "The senior examiner still decides."
            )
            st.session_state.messages.append({"role": "assistant", "content": note})
            st.session_state.show_decision = False
            st.rerun()

    if sent_back:
        question = (
            "The claims officer sent this file back. "
            "Say what is still unclear. Do not pay or decline. "
            "The original question was: "
            + (st.session_state.last_question or "Is this loss covered?")
        )
        print(
            f"Desk decision: send back {claim_id}. Calling the crew again. {question}",
            flush=True,
        )
        with st.spinner("The crew is reading the file again..."):
            try:
                answer = respond(question, CLAIMS[claim_id])
            except Exception as exc:
                print(
                    f"Desk decision: send back on {claim_id} failed. {exc}",
                    flush=True,
                )
                answer = f"The desk could not finish.\n\n{exc}"
        st.session_state.messages.append({"role": "user", "content": "Send this file back."})
        st.session_state.messages.append({"role": "assistant", "content": answer})
        waiting = answer.startswith("DESK ROUTE: ask_the_crew")
        st.session_state.show_decision = waiting
        st.session_state.decision_claim = claim_id if waiting else None
        if waiting:
            print(
                f"Desk decision: {claim_id} is waiting again after send back. Three buttons. Not a payment.",
                flush=True,
            )
        else:
            print(
                f"Desk decision: send back on {claim_id} did not return a crew note. No buttons.",
                flush=True,
            )
        st.rerun()

st.rerun starts the script again so the new note appears in the history and the buttons do not fire twice. st.session_state survives that rerun. The chat bubbles do not. The bubbles are rebuilt from messages, which is why the note is appended there before the rerun.

The print lines are the decision log. They use flush=True so they show up while a crew is still running. The previous page's Chat:, Desk:, and Crew start: lines still print, because desk.py is unchanged. A button that does not call respond prints only Desk decision:.

What just happened

  • Human in the loop means the procedure stops for a person. Here that person is the claims officer, and only after the crew has written.
  • The pause is st.session_state, because Streamlit forgets ordinary variables on every click. @human_feedback and Flow.ask would pause the terminal instead, and the browser would not show a button.
  • Accept, Change amount, and Send back are decisions about the note. The senior examiner is still the one who can bind a payment or a denial.
  • Switching claims clears the waiting decision, so a button for CLM-20481 cannot act on CLM-10021. The terminal says Buttons cleared.
  • Desk decision: is the page. Crew start: is the crew. Accept, a refused figure, and a changed figure print the first and not the second. Send back prints both.
