Your First Coverage Officer Agent

A small chat for a made-up insurance company. You pick one car-accident file and ask a question. One AI worker reads that file and writes a note. The note does not pay anyone.

How to follow this page. Do Step 1 through Step 10 in that order. Copy every code block exactly as it is shown. The code has already been tested for this exercise, so do not rewrite it. After a step, check the sentence that says what you should see. If you do not see that, use the table at the end of the page before you continue. You do not need insurance experience, and you do not need to have used CrewAI before. The first time a special word appears, its meaning is in parentheses beside it.

The story, in plain words

Suraksha General Insurance is a made-up company. It sells car insurance (a contract that says when the company will pay for damage to a car). A customer has an accident and asks the company to pay the garage. That request is a claim (one file: what happened, which contract the customer bought, and the garage bill).

You are the claims officer (the human at the keyboard). You prepare the file. You do not send the money. A senior examiner (a more senior human who is not in this chat) is the only person who can say "pay this" or "do not pay this".

The note you need is a coverage opinion (a first reading of "does this contract seem to cover this accident?"). The opinion is preliminary (a first draft, not the last word) and non-binding (nobody has to pay because of it).

We will build the note-writer as one agent (an AI worker with a job title, a goal, and rules for how it behaves). CrewAI is the toolkit that runs that worker. This agent's job title is coverage officer, so I will call it the coverage officer agent. You will talk to it in a chat (a web page where you type a question and read the reply). You pick a claim, you ask a question, and you read the opinion.

You and the agent are two different roles. You ask. The agent answers. On this page the agent cannot look anything up. It has no database (a stored table of records) and no search. Everything it is allowed to know is written into the task (the one job we give it, including the accident story and your question). If a fact is not in that text, the agent must say the fact is missing. It must not guess.

Why one file is harder than the others. Look at claim CLM-20481, which we will use in a moment. A claim id (the short code, such as CLM-20481) is only a label for the file. The policy (the insurance contract) says the company does not pay when the driver has no valid licence (legal permission to drive). An internal note, circular CL-17 (a short office rule that tells staff how to apply the contract), says something softer: if the licence expired within the last 30 days, send the file to a senior examiner. Do not reject it on the spot. In this accident the licence expired 12 days earlier, and the police report does not match what the customer said. A careful reader can hold those sentences together. That reading is the task we will give this agent. We are not asking it to release any money.
These claims are made up. The policy numbers, places, and amounts are for class. Amounts are in Indian rupees (₹, also written INR in the files). The agent's reply is an opinion for a human to read. It must not say the claim has been paid or rejected.

The three claims

The chat will offer these three files. Read them once now, so the answers later make sense. Own damage means damage to the customer's own car, such as a bumper that needs a repaint. An estimate is the garage's bill for the repair. Papers are the documents in the file, such as the customer's report, photos, or a police report.

Step 1: Install the CrewAI command

In this step you install CrewAI (the toolkit that will run the agent). Open a terminal (the window where you type commands). On Windows, use PowerShell. Check Python first:

python --version

Install uv. On Windows, in PowerShell:

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

On macOS or Linux:

curl -LsSf https://astral.sh/uv/install.sh | sh

Then install CrewAI and confirm the command works:

uv --version
uv tool install crewai
uv tool update-shell
crewai version

When this step works, crewai version prints a version number. If the terminal says crewai is not found, close it, open a new one, and try crewai version again. If you already installed CrewAI earlier and it is old, run uv tool install crewai --upgrade.

Step 4: Describe the coverage officer agent

In this step you write the agent's job description. Create the file agents/coverage_officer.jsonc and paste the block below exactly. The name of the file, without .jsonc, is the agent's id (the short name other files use to point at this agent). I have left out tools (lookups the agent could call) on purpose. With no tools, the agent can only read the text we hand it in the task. When this step works, that file exists and there is no researcher.jsonc left in agents/.

{
  "role": "Coverage Officer for claim {claim_id}",
  "goal": "Give a preliminary coverage opinion for {claim_id} using only the narrative, policy excerpt, and known facts supplied in the task.",
  "backstory": "You are a coverage officer at Suraksha General Insurance in India. You interpret policy wording and short internal circulars. You do not look up other systems. You do not invent policy numbers, dates, amounts, or documents that are absent from the task. You never mark a claim paid or declined. A senior examiner binds every payment and every denial.",
  "llm": "openai/gpt-4o-mini",
  "settings": {
    "verbose": true,
    "allow_delegation": false,
    "max_iter": 8
  }
}
How to read this file

role is the job title the agent works under. goal is what "finished" looks like. backstory is the manner I want: quote the policy lines you were given, admit when something is missing, and stop before deciding the money. Words in curly braces, such as {claim_id}, are blanks. They are filled in from the claim when the task starts. llm is the model (the AI that writes the sentences). allow_delegation set to false means this worker cannot hand the job to another worker. There is no other worker yet. max_iter is how many tries the agent gets before it must answer. verbose prints the agent's steps in the terminal, so you can see that it is only reading.

# ===== CHANGE THIS FUNCTION =====
def respond(user_message: str, claim: dict) -> str:
    """Answer the question using only the selected claim."""
    crew, defaults = _get_crew()
    inputs = {**defaults, **claim_to_inputs(claim, user_message)}
    result = crew.kickoff(inputs=inputs)
    return result.raw
# ===== END OF THE CHANGE =====

Here is what that function does, in order. load_crew reads crew.jsonc and builds the crew: the coverage officer agent and its task. We put the claim you selected, and the question you typed, on top of the sample inputs. kickoff (the command that starts the crew) runs the task. result.raw is the opinion text, which we hand back to the chat. The first question takes longer, because the crew is loaded on that first call and then kept for the next questions. When this step works, desk.py no longer contains the sentence "The coverage officer is not connected yet."

Step 9: The chat window

In this step you open the page you will actually use. Create app.py and paste it exactly as given. This file only draws the page and calls respond. You do not need to change the layout to finish the exercise. Streamlit (the library that turns this Python file into a web page) is added by the first command below.

import streamlit as st

from desk import respond
from sample_claims import CLAIM_ORDER, CLAIMS

st.set_page_config(page_title="Suraksha Claims Desk", layout="centered")
st.title("Suraksha Claims Desk")
st.caption("One coverage officer agent. It can use only the text in the selected claim.")

if "messages" not in st.session_state:
    st.session_state.messages = []
if "active_claim" not in st.session_state:
    st.session_state.active_claim = CLAIM_ORDER[0]
if "pending_prompt" not in st.session_state:
    st.session_state.pending_prompt = None

with st.sidebar:
    st.header("Claim file")
    claim_id = st.radio(
        "Select a claim",
        CLAIM_ORDER,
        format_func=lambda cid: f"{cid} — {CLAIMS[cid]['title']}",
    )
    st.markdown(CLAIMS[claim_id]["narrative"])
    st.divider()
    st.subheader("Try these")
    for prompt in (
        "Is this loss covered?",
        "What is the chassis number?",
        "Should we pay this claim now?",
    ):
        if st.button(prompt, use_container_width=True):
            st.session_state.pending_prompt = prompt

if st.session_state.active_claim != claim_id:
    st.session_state.messages = []
    st.session_state.active_claim = claim_id

for message in st.session_state.messages:
    with st.chat_message(message["role"]):
        st.markdown(message["content"])

typed = st.chat_input("Ask the coverage officer agent about the selected claim")
user_text = st.session_state.pending_prompt or typed
if st.session_state.pending_prompt:
    st.session_state.pending_prompt = None

if user_text:
    st.session_state.messages.append({"role": "user", "content": user_text})
    with st.chat_message("user"):
        st.markdown(user_text)
    with st.chat_message("assistant"):
        with st.spinner("The coverage officer agent is reading the file..."):
            try:
                answer = respond(user_text, CLAIMS[claim_id])
            except Exception as exc:
                answer = f"The desk could not complete the opinion.\n\n{exc}"
        st.markdown(answer)
    st.session_state.messages.append({"role": "assistant", "content": answer})
