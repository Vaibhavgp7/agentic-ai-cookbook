A Manager Assigns the Work

The same Suraksha chat. The same two specialists. A manager now decides which worker does each job.

How to follow this page. You already have two agents and two tasks that run in a fixed order. Do the steps in order. Copy the new lines exactly. Do not add a third agent file. After Step 4, read the terminal before you trust the chat. New words are explained in parentheses the first time they appear.

The story, in plain words

You are still the claims officer (the human at the keyboard). The coverage officer agent writes the coverage opinion (the first reading of the file). The examiner brief agent writes the brief (the short note for the senior examiner, who is a person outside this chat). Right now each task is pinned to one agent. The process is sequential (the tasks run in the order they are written, and the named agent does that task). Nobody chooses the worker.

A claims desk does choose. The person who opens the policy is not the person who writes the note for the senior examiner. CrewAI can add a third worker for that choice. You do not write a third agent file. You change the process to hierarchical (a manager receives each task and hands it to one specialist). You name a model for the manager. CrewAI then creates an agent whose role is Crew Manager. The manager does not open the database. The manager's only job is to delegate (hand the job to one of the two agents you already have).

The task list is still walked from top to bottom. The coverage opinion still runs before the brief, because the brief's context (the earlier answer it is allowed to read) names coverage_opinion. What changes is who is handed the work. Leave allow_delegation set to false on both specialists. If they can hand work to each other, the manager is no longer the only one assigning it.

The manager must not pay or decline. The senior examiner is still the human who binds a payment or a denial. The manager only assigns the coverage opinion and the brief. Both answers stay non-binding.
Hierarchical needs a manager model. If process is hierarchical and you do not set manager_llm, the crew fails before the first task. The message says that manager_llm or manager_agent is required. Use manager_llm. Do not add a manager to the agents list, and do not give the manager a tool.

def _get_crew():
    global _crew, _defaults
    if _crew is None:
        _crew, _defaults = load_crew(Path(__file__).parent / "crew.jsonc")
        coverage_officer = _crew.agents[0]
        # The manager hands this agent a fresh task.
        # A tool pinned only to coverage_opinion does not travel with that handoff.
        coverage_officer.tools = list(coverage_officer.tools or []) + [earlier_claims]
    return _crew, _defaults
