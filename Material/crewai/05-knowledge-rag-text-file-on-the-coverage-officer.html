Claims manual, internal use
This file is not a row in the policies table.

When the garage estimate is more than twice a typical surveyor figure for the same description, the file is called a high-variance estimate. Record both figures and refer the variance to the senior examiner. The words high-variance estimate are defined only in this manual.

This manual does not replace Policy Record. A licence that lapsed fewer than 30 days before the accident is still handled by circular CL-17 in the policy row. This manual is not a reason to pay a claim and not a reason to decline a claim.

Optional: store the files once, inside the app

It only stops the app from reading those two files again on every restart. A knowledge_sources block on the agent means the knowledge sources will be reloaded during the app start or restart. An embedder (the model that turns a passage into numbers so a later question can search by meaning) is named in the code below. Leave that model name as written. load_crew reads crew.jsonc and the agent file, and it builds those sources while it creates the crew. A large folder of manuals would repeat that work on every app start and every app restart. The same sentence is not stored twice, because its id is a hash (a fingerprint of the text) of the text, but the embedding call still runs.

3. Check that both files are present

_manual_files_present looks in the project knowledge folder. It returns true only when the text manual and the PDF are both there. If either file is missing, the later function leaves the crew alone, and the chat still answers from Policy Record.

def _manual_files_present() -> bool:
    knowledge = ROOT / "knowledge"
    return (knowledge / "claims_manual.txt").is_file() and (
        knowledge / "cl22_injury_bill_circular.pdf"
    ).is_file()

4. See whether the passages are already stored

CrewAI keeps this collection under the name knowledge_suraksha_manuals. _stored_collection_names asks the local store for the names it already has. The next function uses that list to decide whether this app start should embed the files.

Add this function under the previous one
def _stored_collection_names(knowledge) -> set[str]:
    client = knowledge.storage._get_client().client
    return {collection.name for collection in client.list_collections()}

5. Decide the knowledge object before the crew exists

_open_manuals does not call load_crew and does not touch an agent. It runs first, during the app start/restart. It opens collection suraksha_manuals with an empty source list. If knowledge_suraksha_manuals is already stored, it returns that object and the files stay unread. If the collection is missing, it builds the text file and the PDF, calls add_sources() once, and returns that loaded object. If either file is missing, it returns None and the chat still answers from Policy Record.

Add this function under the previous one
def _open_manuals():
    """Choose the knowledge object before load_crew reads crew.jsonc.

    An empty source list means this app start does not read the files.
    The files are read only when the collection is missing.
    """
    if not _manual_files_present():
        print(
            "Knowledge check: claims_manual.txt or cl22_injury_bill_circular.pdf "
            "is missing from the knowledge folder. No knowledge sources were loaded.",
            flush=True,
        )
        return None

    from crewai.knowledge.knowledge import Knowledge
    from crewai.knowledge.source.pdf_knowledge_source import PDFKnowledgeSource
    from crewai.knowledge.source.text_file_knowledge_source import TextFileKnowledgeSource

    stored = Knowledge(
        collection_name=KNOWLEDGE_COLLECTION,
        sources=[],
        embedder=KNOWLEDGE_EMBEDDER,
    )
    if f"knowledge_{KNOWLEDGE_COLLECTION}" in _stored_collection_names(stored):
        print(
            "Knowledge check: collection suraksha_manuals is already stored. "
            "Knowledge sources were not loaded again on this app start.",
            flush=True,
        )
        return stored

    print(
        "Knowledge check: collection suraksha_manuals is missing. "
        "Loading knowledge sources claims_manual.txt and cl22_injury_bill_circular.pdf.",
        flush=True,
    )
    loaded = Knowledge(
        collection_name=KNOWLEDGE_COLLECTION,
        sources=[
            TextFileKnowledgeSource(file_paths=["claims_manual.txt"]),
            PDFKnowledgeSource(file_paths=["cl22_injury_bill_circular.pdf"]),
        ],
        embedder=KNOWLEDGE_EMBEDDER,
    )
    loaded.add_sources()
    return loaded

6. Hand that object to the coverage officer after the crew is created

_get_crew calls _open_manuals() first and keeps the result in manuals. Only then does it call load_crew. Because step 1 removed knowledge_sources, that call creates the crew without loading the manual or the PDF. After the crew exists, the first agent is named coverage_agent. Its knowledge_sources is set to an empty list, so a later question cannot embed the files from the JSON. coverage_agent.knowledge is the object _open_manuals already returned. The brief writer is the second agent and is left unchanged. Earlier Claims stays pinned to the coverage task.

Replace _get_crew in desk.py with this function
def _get_crew():
    global _crew, _defaults
    if _crew is None:
        manuals = _open_manuals()
        _crew, _defaults = load_crew(Path(__file__).parent / "crew.jsonc")
        coverage_task = _crew.tasks[0]
        # This task keeps the policy tool and adds the garage tool.
        # The agent's own list is left unchanged.
        coverage_task.tools = list(coverage_task.tools or []) + [earlier_claims]
        coverage_agent = _crew.agents[0]
        # crew.jsonc must not list knowledge_sources. An empty list here
        # keeps a later question from embedding the files again.
        coverage_agent.knowledge_sources = []
        if manuals is not None:
            coverage_agent.knowledge = manuals
    return _crew, _defaults

Leave respond as it is. It already calls _get_crew. The if _crew is None block runs during the app start/restart, not on a later question in the same running app.
