Streamlit Chatbot with Persistent Memory

This lab has two parts. First you learn Streamlit basics (assuming you have never used it before). Then you build a chatbot with persistent memory using the SqliteSaver checkpointer from Section 5 of 03using-agents-part1.html.

By the end you will have a Streamlit app that:

  • Can answer questions using Tavily web search for up-to-date information.
  • Uses SqliteSaver for persistent agent memory.

  • Shows a sidebar with a New Chat button and a dropdown of previous threads.
  • Loads the correct chat history when you switch threads.

1. What Is Streamlit?

Streamlit is a Python library for building web apps quickly. You write normal Python — no HTML, CSS, or JavaScript required. Streamlit turns your script into a live webpage in the browser.

Typical use cases: dashboards, data explorers, internal tools, and chatbots (like we will build).

1.1 How Streamlit Works (Important!)

Every time you click a button, type in a box, or send a chat message, Streamlit reruns your entire Python file from top to bottom. That sounds strange at first, but it keeps apps simple: you always describe what the UI should look like right now.

Because the script reruns constantly, regular Python variables are reset. To remember data between reruns (like a click count or chat history), you use st.session_state — you will practice that in Section 4.

1.2 Streamlit Vocabulary

  • import streamlit as st — always import Streamlit as st.
  • st.title(...), st.write(...) — display text on the page.
  • st.button(...), st.text_input(...) — widgets the user can interact with.
  • st.sidebar — a panel on the left side of the page.
  • st.chat_message(...), st.chat_input(...) — built-in chat UI components.
  • st.session_state — a dict that survives reruns within the same browser tab.
  • st.rerun() — tell Streamlit to rerun the script immediately (useful after updating state).

4. Session State — Remember Data Between Reruns

Without st.session_state, a counter would always reset to zero on every rerun. Session state is how Streamlit apps remember things like chat history, selected thread, or a click count.

Your Task

Replace hello_streamlit.py with this counter example. Save and test the button several times.

import streamlit as st

st.title("Session State Demo")

# Create the counter once; keep it across reruns
if "count" not in st.session_state:
    st.session_state.count = 0

st.write(f"Button clicked **{st.session_state.count}** time(s).")

if st.button("Click me"):
    st.session_state.count += 1
    st.rerun()

What to notice

  • Each click increases the count — the value is not lost when Streamlit reruns.
  • st.rerun() refreshes the page so the new count shows immediately.
  • Our chatbot will store the active thread_id in session state the same way.

5. Sidebar and Chat UI

Most chat apps put controls (new chat, thread list) in a sidebar and messages in the main area. Streamlit has ready-made chat components so you do not have to build bubbles from scratch.

5.2 Chat messages (echo bot, no AI yet)

st.chat_message draws a message bubble. st.chat_input is the text box at the bottom. This mini echo bot stores messages in session state — the same pattern our real chatbot will use.

Your Task

Replace hello_streamlit.py with this echo chatbot. Save and send a few messages.

import streamlit as st

st.set_page_config(page_title="Echo Chat", layout="wide")
st.title("Echo Chat (no AI — just Streamlit UI practice)")

with st.sidebar:
    st.header("Sidebar")
    if st.button("Clear chat"):
        st.session_state.messages = []
        st.rerun()

# Remember messages between reruns
if "messages" not in st.session_state:
    st.session_state.messages = []

# Show all past messages
for message in st.session_state.messages:
    with st.chat_message(message["role"]):
        st.markdown(message["content"])

# Read new input from the user
if prompt := st.chat_input("Type a message..."):
    st.session_state.messages.append({"role": "user", "content": prompt})
    st.session_state.messages.append({"role": "assistant", "content": f"You said: {prompt}"})
    st.rerun()

Try this

  1. Send a few messages — they stay visible (session state).
  2. Click Clear chat in the sidebar — history disappears.
  3. This is the same UI pattern we will connect to a LangChain agent next.

6. Build the Memory Chatbot

Now connect Streamlit to a LangChain agent with SqliteSaver and a Tavily web search tool. Create a new file: streamlit_chatbot.py (separate from the warmup file).

Key idea — two pieces of storage
  • checkpoints.sqlite — LangGraph stores full agent state (messages) per thread_id.
  • chat_threads.json — a tiny list of thread ids for the sidebar dropdown (we keep this separate so the UI stays simple).

When you switch threads in the dropdown, Streamlit reads messages from the checkpointer using agent.get_state(...) and redraws the chat on the right.

6.3 Step 2 — Create the Agent with SqliteSaver and Tavily

Add imports and build one agent backed by SQLite. We also attach the LangChain Tavily search tool so the agent can look up current information on the web. We use @st.cache_resource so the agent is created only once (Streamlit reruns the whole script on every click).

Your Task

Replace the contents of streamlit_chatbot.py with the code below. Save and refresh the browser.

import sqlite3
import streamlit as st
from dotenv import load_dotenv
from langchain.agents import create_agent
from langchain_openai import ChatOpenAI
from langchain_tavily import TavilySearch
from langgraph.checkpoint.sqlite import SqliteSaver

load_dotenv()

CHECKPOINT_DB = "checkpoints.sqlite"

@st.cache_resource
def get_agent():
    conn = sqlite3.connect(CHECKPOINT_DB, check_same_thread=False)
    checkpointer = SqliteSaver(conn=conn)
    checkpointer.setup()  # create tables if needed

    model = ChatOpenAI(model="gpt-4o-mini", temperature=0)

    tavily_tool = TavilySearch(
        max_results=3,
        search_depth="advanced",
        include_answer=True,
        include_raw_content=False,
        include_images=False,
    )

    return create_agent(
        model=model,
        tools=[tavily_tool],
        system_prompt=(
            "You are a helpful assistant with access to web search. "
            "Use web search when the user asks about current events, recent news, "
            "live data, or anything that needs up-to-date information from the internet. "
            "For personal facts the user told you earlier in the same chat, use memory — do not search the web."
        ),
        checkpointer=checkpointer,
    )

st.set_page_config(page_title="Memory Chatbot", layout="wide")
st.title("Chatbot with Memory")

agent = get_agent()
st.success("Agent ready. SqliteSaver + Tavily web search connected.")

What you should see

A green success message: Agent ready. SqliteSaver + Tavily web search connected.

A file named checkpoints.sqlite appears in your project folder.

6.4 Step 3 — Chat on One Thread (Memory Works)

Before adding multiple chats, prove that memory works on a single fixed thread. Every message uses the same thread_id. The checkpointer remembers prior turns.

Your Task

Add the chat UI below the line agent = get_agent(). Remove the success message line.

# --- Single-thread demo (fixed thread_id) ---
THREAD_ID = "demo-thread-1"
config = {"configurable": {"thread_id": THREAD_ID}}

st.caption(f"Using thread: `{THREAD_ID}`")

# Load existing messages from the checkpointer
snapshot = agent.get_state(config)
stored_messages = snapshot.values.get("messages", [])

# Show history
for msg in stored_messages:
    if msg.type == "human":
        with st.chat_message("user"):
            st.markdown(msg.content)
    elif msg.type == "ai" and msg.content:
        with st.chat_message("assistant"):
            st.markdown(msg.content)

# New user input
if prompt := st.chat_input("Say something..."):
    agent.invoke(
        {"messages": [{"role": "user", "content": prompt}]},
        config,
    )
    st.rerun()

6.5 Step 4 — Generate a Unique Thread ID

Real apps give each conversation its own id. We use Python's uuid module. st.session_state keeps the current thread id while Streamlit reruns the script.

Your Task

At the top, add import uuid. Replace the fixed THREAD_ID = "demo-thread-1" block with the session-state version below. 

import uuid
# --- One thread per browser session (unique id) ---
if "thread_id" not in st.session_state:
    st.session_state.thread_id = str(uuid.uuid4())

A random UUID shown under the title (for example a3f1b2c4-...). Refreshing the browser keeps the same id; opening a new incognito window gets a new id.

6.6 Step 5 — Sidebar: New Chat Button

Add a left sidebar. Clicking New Chat creates a fresh UUID and clears the main chat area. We also save thread ids to chat_threads.json so the dropdown can list them later.

Your Task

Add import json and import os at the top. Add the helper functions and sidebar code below, before the chat UI section.

import json
import os
THREADS_FILE = "chat_threads.json"

def load_threads():
    if os.path.exists(THREADS_FILE):
        with open(THREADS_FILE, encoding="utf-8") as f:
            return json.load(f)
    return []

def save_threads(threads):
    with open(THREADS_FILE, "w", encoding="utf-8") as f:
        json.dump(threads, f)

def add_thread(thread_id):
    threads = load_threads()
    if any(t["id"] == thread_id for t in threads):
        return
    threads.insert(0, {"id": thread_id, "label": f"Chat {thread_id[:8]}"})
    save_threads(threads)

# Pick a thread when the app first opens
if "thread_id" not in st.session_state:
    threads = load_threads()
    if threads:
        st.session_state.thread_id = threads[0]["id"]
    else:
        st.session_state.thread_id = str(uuid.uuid4())
        add_thread(st.session_state.thread_id)

# --- Sidebar ---
with st.sidebar:
    st.header("Chats")

    if st.button("➕ New Chat", use_container_width=True):
        new_id = str(uuid.uuid4())
        add_thread(new_id)
        st.session_state.thread_id = new_id
        st.rerun()

    st.caption(f"Active thread:\n`{st.session_state.thread_id}`")

Remove the old if "thread_id" not in st.session_state block from Step 6.5 — the new block above replaces it. Also remove the standalone st.caption(f"Thread ID: ...") line; the sidebar now shows the active thread.

Try this

  1. Send a message in the main chat.
  2. Click New Chat in the sidebar — the chat area should be empty.
  3. Send a different message in the new chat.

6.7 Step 6 — Dropdown to Switch Threads

This is the core lesson: when you pick another thread from the dropdown, Streamlit changes st.session_state.thread_id and reloads messages from the checkpointer. Each thread has its own isolated history in checkpoints.sqlite.

Your Task

Inside the with st.sidebar: block, add the selectbox code below (after the New Chat button).

    threads = load_threads()
    if threads:
        labels = [t["label"] for t in threads]
        ids = [t["id"] for t in threads]

        current_index = ids.index(st.session_state.thread_id)
        picked_label = st.selectbox(
            "Previous chats",
            labels,
            index=current_index,
        )
        picked_id = ids[labels.index(picked_label)]

        if picked_id != st.session_state.thread_id:
            st.session_state.thread_id = picked_id
            st.rerun()

Try this — the memory demo

  1. In Chat A, say: My favorite color is blue.
  2. Click New Chat to open Chat B.
  3. In Chat B, say: My favorite color is green.
  4. Use the dropdown to switch back to Chat A.
  5. Ask: What is my favorite color? — the answer should be blue, not green.
  6. Switch to Chat B and ask the same question — the answer should be green.
  7. In either chat, ask something that needs the web, e.g. Search the web: who won the latest Formula 1 race? — Tavily should run and the agent should summarize results.
What just happened?

Both chats use the same agent, but different thread_id values in config = {"configurable": {"thread_id": ...}}. SqliteSaver stores separate checkpoint rows per thread. When you change the dropdown, agent.get_state(config) reads the messages for that thread only.

6.8 Final Code — Complete App

Below is the full, minimal app. Compare it with your file — every piece should match if you followed each step.

Your Task

Optionally replace your entire file with this version to verify everything is correct. Save, refresh, and run the memory demo from Step 6.7 again. 

import json
import os
import sqlite3
import uuid

import streamlit as st
from dotenv import load_dotenv
from langchain.agents import create_agent
from langchain_openai import ChatOpenAI
from langchain_tavily import TavilySearch
from langgraph.checkpoint.sqlite import SqliteSaver

load_dotenv()

CHECKPOINT_DB = "checkpoints.sqlite"
THREADS_FILE = "chat_threads.json"


@st.cache_resource
def get_agent():
    conn = sqlite3.connect(CHECKPOINT_DB, check_same_thread=False)
    checkpointer = SqliteSaver(conn=conn)
    checkpointer.setup()

    model = ChatOpenAI(model="gpt-4o-mini", temperature=0)

    tavily_tool = TavilySearch(
        max_results=3,
        search_depth="advanced",
        include_answer=True,
        include_raw_content=False,
        include_images=False,
    )

    return create_agent(
        model=model,
        tools=[tavily_tool],
        system_prompt=(
            "You are a helpful assistant with access to web search. "
            "Use web search when the user asks about current events, recent news, "
            "live data, or anything that needs up-to-date information from the internet. "
            "For personal facts the user told you earlier in the same chat, use memory — do not search the web."
        ),
        checkpointer=checkpointer,
    )


def load_threads():
    if os.path.exists(THREADS_FILE):
        with open(THREADS_FILE, encoding="utf-8") as f:
            return json.load(f)
    return []


def save_threads(threads):
    with open(THREADS_FILE, "w", encoding="utf-8") as f:
        json.dump(threads, f)


def add_thread(thread_id):
    threads = load_threads()
    if any(t["id"] == thread_id for t in threads):
        return
    threads.insert(0, {"id": thread_id, "label": f"Chat {thread_id[:8]}"})
    save_threads(threads)


# --- Page setup ---
st.set_page_config(page_title="Memory Chatbot", layout="wide")
st.title("Chatbot with Memory")

agent = get_agent()

# --- Pick active thread ---
if "thread_id" not in st.session_state:
    threads = load_threads()
    if threads:
        st.session_state.thread_id = threads[0]["id"]
    else:
        st.session_state.thread_id = str(uuid.uuid4())
        add_thread(st.session_state.thread_id)

# --- Sidebar: new chat + thread picker ---
with st.sidebar:
    st.header("Chats")

    if st.button("➕ New Chat", use_container_width=True):
        new_id = str(uuid.uuid4())
        add_thread(new_id)
        st.session_state.thread_id = new_id
        st.rerun()

    threads = load_threads()
    if threads:
        labels = [t["label"] for t in threads]
        ids = [t["id"] for t in threads]
        current_index = ids.index(st.session_state.thread_id)
        picked_label = st.selectbox("Previous chats", labels, index=current_index)
        picked_id = ids[labels.index(picked_label)]
        if picked_id != st.session_state.thread_id:
            st.session_state.thread_id = picked_id
            st.rerun()

    st.caption(f"Active thread:\n`{st.session_state.thread_id}`")

# --- Main chat area (right side) ---
config = {"configurable": {"thread_id": st.session_state.thread_id}}
snapshot = agent.get_state(config)

for msg in snapshot.values.get("messages", []):
    if msg.type == "human":
        with st.chat_message("user"):
            st.markdown(msg.content)
    elif msg.type == "ai" and msg.content:
        with st.chat_message("assistant"):
            st.markdown(msg.content)

if prompt := st.chat_input("Say something..."):
    agent.invoke(
        {"messages": [{"role": "user", "content": prompt}]},
        config,
    )
    st.rerun()
