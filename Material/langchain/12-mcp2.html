I wrote this lab for you. By the end of it, you will have built your own MCP servers, connected them to VS Code, written Python clients, and handed those tools to a LangChain agent. We will start with a Database Server, then add a File System Server, then try Streamable HTTP, and finally wire everything into LangChain with the built-in MCPAdapter.

  3. Copy the code I give you into the filename I name. Run it. Look at the output before you move on.

The two objects you will use throughout this lab
On the server side, you create an MCPServer and decorate Python functions with @mcp.tool(). You start it with mcp.run() — that is where you pass the transport (stdio by default, or Streamable HTTP with a port).
On the client side, you use a single Client object. Pass it a transport, enter async with, then call list_tools() and call_tool(). The connection is ready as soon as you enter the context manager. Official reference: Client transports.

Step 1: Introduction to MCP

MCP (Model Context Protocol) is how a language model talks to tools you write. You expose ordinary Python functions. The model can then call those functions to query a database, read a file, or send mail through Gmail — instead of guessing.

Think of an MCP server as a small program that says: “Here are the tools I offer. Call them with these arguments.” VS Code, a Python script, or a LangChain agent can all be the client on the other side.

Step 2: Install the MCP SDK

The servers and Python clients in this lab use the official MCP SDK (from mcp.server import MCPServer). LangChain talks to those same servers through langchain.mcp.MCPAdapter, which needs langchain[mcp] >= 1.4.0 (FastMCP 4, which itself uses MCP 2.x). Those packages are compatible. Step 3: Creating the 03-DatabaseServer.py

We start with a Database MCP server. I want you to give the model four tools: connect to SQLite, list tables, read a table schema, and run a query.

I have given you a SQLite file named fintech.db. Copy it to C:\database before you continue — every example in this lab points there.

Create a file named 03-DatabaseServer.py in your workspace and paste the code below into it. 

from mcp.server import MCPServer
import sqlite3
from typing import List, Dict, Any, Optional
from pathlib import Path

# Create an MCP server
mcp = MCPServer("DatabaseServer")

@mcp.tool()
def connect_database(db_path: str) -> str:
    """Connect to a SQLite database"""
    try:
        # Ensure the directory exists
        Path(db_path).parent.mkdir(parents=True, exist_ok=True)
        # Test connection
        conn = sqlite3.connect(db_path)
        conn.close()
        return f"Successfully connected to database at {db_path}"
    except Exception as e:
        return f"Error connecting to database: {str(e)}"

@mcp.tool()
def list_tables(db_path: str) -> List[str]:
    """List all tables in the database"""
    try:
        conn = sqlite3.connect(db_path)
        cursor = conn.cursor()
        cursor.execute("SELECT name FROM sqlite_master WHERE type='table';")
        tables = [row[0] for row in cursor.fetchall()]
        conn.close()
        return tables
    except Exception as e:
        return [f"Error listing tables: {str(e)}"]

@mcp.tool()
def get_table_schema(db_path: str, table_name: str) -> str:
    """Get schema information for a specific table as a CREATE TABLE string"""
    try:
        conn = sqlite3.connect(db_path)
        cursor = conn.cursor()
        cursor.execute(
            "SELECT sql FROM sqlite_master WHERE type='table' AND name=?;",
            (table_name,),
        )
        row = cursor.fetchone()
        conn.close()
        if row and row[0]:
            return row[0]
        return f"Table '{table_name}' not found"
    except Exception as e:
        return f"Error getting schema: {str(e)}"

@mcp.tool()
def execute_query(db_path: str, query: str) -> List[Dict[str, Any]]:
    """Execute a SQL query and return results"""
    try:
        conn = sqlite3.connect(db_path)
        conn.row_factory = sqlite3.Row
        cursor = conn.cursor()
        cursor.execute(query)
        results = [dict(row) for row in cursor.fetchall()]
        conn.close()
        return results
    except Exception as e:
        return [{"error": f"Error executing query: {str(e)}"}]

if __name__ == "__main__":
    mcp.run()

Step 6: Creating the 01-FileSystemServer.py

Next I want you to build a File System Server. Same idea as the database server, different tools: list files, read, write, create a directory, delete a file.

Create 01-FileSystemServer.py in the same workspace and paste this in: 

from mcp.server import MCPServer
from pathlib import Path
from typing import List

# Create an MCP server
mcp = MCPServer("FileSystemServer")

@mcp.tool()
def list_files(directory: str) -> List:
    """List all files in a directory"""
    try:
        return [f.absolute() for f in Path(directory).iterdir() if f.is_file()]
    
    except Exception as e:
        return [f"Error: {str(e)}"]

@mcp.tool()
def read_file(file_path: str) -> str:
    """Read contents of a file"""
    try:
        with open(file_path, 'r') as f:
            return f.read()
    except Exception as e:
        return f"Error: {str(e)}"

@mcp.tool()
def write_file(file_path: str, content: str) -> str:
    """Write content to a file"""
    try:
        with open(file_path, 'w') as f:
            f.write(content)
            return f"File written successfully to  {f.name}"
    except Exception as e:
        return f"Error: {str(e)}"

@mcp.tool()
def create_directory(directory: str) -> str:
    """Create a new directory"""
    try:
        Path(directory).mkdir(parents=True, exist_ok=True)
        return "Directory created successfully"
    except Exception as e:
        return f"Error: {str(e)}"

@mcp.tool()
def delete_file(file_path: str) -> str:
    """Delete a file"""
    try:
        Path(file_path).unlink()
        return "File deleted successfully"
    except Exception as e:
        return f"Error: {str(e)}"

if __name__ == "__main__": 
    mcp.run()

Step 7: Creating a Stdio Client for the Database Server

Copilot Chat is one client. You can also write your own. I want you to do that next, so you see exactly how a Python program talks to an MCP server.

Every client in this lab is a single Client object. For stdio, you pass stdio_client(StdioServerParameters(...)) into Client, then enter async with. That opens the connection and negotiates for you. After that you call list_tools() and call_tool(). See Client transports if you want the full list of options.

Save the code below as 04-DatabaseServerClient.py. Run it from the same course venv. 

from mcp import Client, StdioServerParameters
from mcp.client.stdio import stdio_client
import asyncio

# StdioServerParameters is configuration only — always wrap with stdio_client(...)
server_params = StdioServerParameters(
    command="python",  # Executable
    args=["03-DatabaseServer.py"],  # Server script
    env=None,  # Pass API keys here if needed; the child does not inherit your full env
)


async def run():
    # Client takes the transport; async with opens the connection
    async with Client(stdio_client(server_params)) as client:
        # List available tools
        tools = await client.list_tools()
        print("Available tools:", [tool.name for tool in tools.tools])

        db_path = "c:\\database\\fintech.db"

        # call_tool returns CallToolResult — prefer structured_content for application code
        tables = await client.call_tool("list_tables", {"db_path": db_path})
        print("Tables in database:", tables.structured_content)

        schema = await client.call_tool("get_table_schema", {
            "db_path": db_path,
            "table_name": "customers"
        })
        print("Table schema for customers:", schema.structured_content)

        results = await client.call_tool("execute_query", {
            "db_path": db_path,
            "query": "SELECT * FROM customers LIMIT 5"
        })
        print("First 5 customers:", results.structured_content)

if __name__ == "__main__":
    asyncio.run(run())

Run it from the folder where your scripts live: 

python 04-DatabaseServerClient.py

This client starts DatabaseServer, connects to fintech.db, lists tables, fetches the schema of customers, and prints the first 5 rows.

In-memory client (no subprocess).
When you are testing, you can skip launching a child process. Pass the server object itself: async with Client(mcp) as client:. Same list_tools / call_tool API — no port, no bytes on a wire.

Step 8: Creating a Database Server with Streamable HTTP

Stdio is great when the client starts the server as a child process. When the client and server live in different processes (or on different machines), you serve MCP over HTTP instead. Streamable HTTP is the HTTP transport to use for new work. The older HTTP+SSE transport is deprecated in the MCP spec, so we will not use it here.

Name the server with MCPServer(...). Pass transport, port, stateless_http, and json_response to mcp.run(). Save this as 07-DatabaseServerStreamableHTTP.py. 

from mcp.server import MCPServer
import sqlite3
from typing import List, Dict, Any
from pathlib import Path

# Name the server here
mcp = MCPServer("DatabaseServerStreamable")

# Other run() options (examples):

# mcp.run(transport="streamable-http")  # Stateful with session persistence

Step 9: Creating a Streamable HTTP Client

Pass a URL string to Client and you get Streamable HTTP automatically. You only need streamable_http_client yourself if you want custom headers, auth, or timeouts (then build an httpx2.AsyncClient and wrap it). Save this as 08-DatabaseStreamableHTTPClient.py. 

from mcp import Client
import asyncio


async def run():
    # A URL string uses Streamable HTTP
    async with Client("http://localhost:8000/mcp") as client:
        tools = await client.list_tools()
        print(f"Available tools: {[tool.name for tool in tools.tools]}")

        db_path = "c:\\database\\fintech.db"

        tables = await client.call_tool("list_tables", {"db_path": db_path})
        print("Tables in database:", tables.structured_content)

        schema = await client.call_tool("get_table_schema", {
            "db_path": db_path,
            "table_name": "customers"
        })
        print("Table schema for customers:", schema.structured_content)

        results = await client.call_tool("execute_query", {
            "db_path": db_path,
            "query": "SELECT * FROM customers LIMIT 5"
        })
        print("First 5 customers:", results.structured_content)


if __name__ == "__main__":
    asyncio.run(run())
Custom HTTP client (auth / headers / timeouts). Build your own httpx2.AsyncClient and pass it to streamable_http_client(url, http_client=...), then Client(transport). Headers, timeouts, and redirects all live on the httpx client. 
import httpx2
from mcp import Client
from mcp.client.streamable_http import streamable_http_client
import asyncio


async def run():
    async with httpx2.AsyncClient(
        headers={"Authorization": "Bearer ..."},
        timeout=httpx2.Timeout(30.0, read=300.0),
        follow_redirects=True,
    ) as http_client:
        transport = streamable_http_client(
            "http://localhost:8000/mcp",
            http_client=http_client,
        )
        async with Client(transport) as client:
            tools = await client.list_tools()
            print([tool.name for tool in tools.tools])


if __name__ == "__main__":
    asyncio.run(run())

Keep 07-DatabaseServerStreamableHTTP.py running. In a second terminal (same course venv), run: 

python 08-DatabaseStreamableHTTPClient.py

The client connects to the Streamable HTTP server, lists available tools, lists tables, shows the schema for the customers table, and fetches the first 5 rows from fintech.db.

Step 10: Integrating MCP Database Server with LangChain

Stay in the same course venv. LangChain talks MCP through langchain.mcp.MCPAdapter (requires langchain[mcp] >= 1.4.0, built on FastMCP 4). That extra sits next to the MCP SDK you already installed.

Your Task – Install langchain[mcp]

In the same venv, install the MCP extra. If you previously installed langchain-mcp-adapters, uninstall it first so it cannot pin MCP 1.x: 

pip uninstall langchain-mcp-adapters
pip install "langchain[mcp]"
MCPAdapter replaces MultiServerMCPClient.
Discover tools with await adapter.list_tools() inside async with MCPAdapter(...), then pass those tools to create_agent. Transport is inferred from the target you pass — you do not set a transport key. The tools hold the client, so the agent stays usable after the context exits. In this lab we keep ainvoke inside the same async with so the script stays simple. Official reference: LangChain MCP. The langchain.mcp namespace is in beta.

Create a LangChain agent that uses DatabaseServer over stdio. Because the server script and LangChain share one Python, a Path target is enough. Save it as 09-LangChainDatabaseAgent.py. 

from pathlib import Path
from langchain.agents import create_agent
from langchain.mcp import MCPAdapter
import asyncio

# Ensure you have OPENAI_API_KEY set in your environment
# os.environ["OPENAI_API_KEY"] = "your-api-key-here"


async def main():
    # Path = local script over stdio (must be Path, not a string)
    async with MCPAdapter(Path("03-DatabaseServer.py")) as adapter:
        tools = await adapter.list_tools()
        print(f"Available tools: {[tool.name for tool in tools]}")

        agent = create_agent("openai:gpt-4o-mini", tools)

        print("\n" + "=" * 80)
        print("List all tables in the fintech database")
        print("=" * 80)
        result = await agent.ainvoke({
            "messages": [{
                "role": "user",
                "content": "List all tables in the database located at c:\\database\\fintech.db",
            }]
        })
        print(f"\nResult: {result['messages'][-1].content}\n")


if __name__ == "__main__":
    asyncio.run(main())
A single Path or URL is not prefixed. You will see tool names such as list_tables and execute_query. With an MCPConfig of several servers, FastMCP names each tool {server}_{tool} (for example database_list_tables) so names never collide.

Before you run the script:

  1. Set your OpenAI API key as an environment variable: set OPENAI_API_KEY=your-api-key-here
  2. Run it from the folder that contains 03-DatabaseServer.py.
  3. Ensure fintech.db is present at c:\database\fintech.db.

Run it: 

python 09-LangChainDatabaseAgent.py

Watch the agent pick MCP tools and answer questions about the database. That reasoning trail is the point of this step — you should see it call list_tables (or similar) instead of inventing an answer.

Optional: other MCPAdapter targets

The only thing that changes between a remote URL, a local script, and several servers is the target you hand MCPAdapter. You do not need these for the exercise above. Use them when the shape of your app is different. 

from pathlib import Path
from langchain.mcp import MCPAdapter

# 1) Streamable HTTP — a string must be an http(s) URL
http = MCPAdapter("http://localhost:8000/mcp")

# 2) Local script over stdio — must be Path, not a string
#    (a string that looks like a file is rejected on purpose)
stdio = MCPAdapter(Path("03-DatabaseServer.py"))

# 3) Several servers in one adapter — mix stdio and HTTP
config = {
    "mcpServers": {
        "filesystem": {
            "command": "python",
            "args": [r"C:\path\to\your\workspace\01-FileSystemServer.py"],
        },
        "database": {"url": "http://localhost:8000/mcp"},
    }
}
fleet = MCPAdapter(config)
When to use which
  • URL string — the server is already running over Streamable HTTP (Step 8).
  • Path — a local .py script over stdio. This is the form used in the example above.
  • MCPConfig — a specific command, env vars, or more than one server. Step 11 uses this.

Need a bearer token on an HTTP server? Build a FastMCP client and pass it in. Skip this unless the server actually requires auth: 

from fastmcp.client import Client
from langchain.mcp import MCPAdapter

async def load_tools(url: str, token: str):
    async with MCPAdapter(Client(url, auth=token)) as adapter:
        return await adapter.list_tools()

Step 11: Using Multiple MCP Servers with LangChain

Stay in the same course venv. One agent can talk to more than one MCP server. Pass an MCPConfig dict to MCPAdapter and it collects tools from all of them, so the same agent can query the database and write a file.

The example below connects to FileSystemServer (stdio) and DatabaseServerStreamable (Streamable HTTP — you start that server yourself in another terminal). Save it as 10-LangChainMultiServerAgent.py. 

from langchain.agents import create_agent
from langchain.mcp import MCPAdapter
import asyncio

# Ensure you have OPENAI_API_KEY set in your environment
# os.environ["OPENAI_API_KEY"] = "your-api-key-here"

config = {
    "mcpServers": {
        "filesystem": {
            "command": "python",
            "args": [r"C:\path\to\your\workspace\01-FileSystemServer.py"],
        },
        "database": {
            # Make sure DatabaseServerStreamableHTTP is running on port 8000
            "url": "http://localhost:8000/mcp",
        },
    }
}


async def main():
    async with MCPAdapter(config) as adapter:
        tools = await adapter.list_tools()
        print(f"Available tools: {[tool.name for tool in tools]}")

        agent = create_agent("openai:gpt-4o-mini", tools)

        print("\n" + "=" * 80)
        print("Multi-Server Task: Query database and save results to file")
        print("=" * 80)
        result = await agent.ainvoke({
            "messages": [{"role": "user", "content": """First, get the first 5 customers from the customers table in c:\\database\\fintech.db.
        Then, write these results to a file named c:\\database\\top5_customers.txt.
        Finally, read and show me the contents of the file."""}]
        })
        print(f"\nResult: {result['messages'][-1].content}\n")

        print("\n" + "=" * 80)
        print("File System Task: List files in database directory")
        print("=" * 80)
        result = await agent.ainvoke({
            "messages": [{"role": "user", "content": "List all files in the c:\\database directory"}]
        })
        print(f"\nResult: {result['messages'][-1].content}\n")


if __name__ == "__main__":
    asyncio.run(main())

Before you run this one:

  1. Ensure your OpenAI API key is set: set OPENAI_API_KEY=your-api-key-here
  2. Update the args path to your 01-FileSystemServer.py file.
  3. In a separate terminal, start the Streamable HTTP server: 
    python 07-DatabaseServerStreamableHTTP.py
  4. Ensure fintech.db is present at c:\database\fintech.db.

Then run the multi-server agent: 

python 10-LangChainMultiServerAgent.py

You should see the agent query the database, write the result to a file, then read that file back — all through one agent that has tools from two servers (database_* and filesystem_*).

Step 12: Using a Gmail MCP Server with LangChain

Stay in the same course venv. You do not have to write every MCP server yourself. In this last step I want you to connect to an existing Gmail server and give its tools to a LangChain agent, so the agent can create a draft and send an email in natural language.

Prefer Google's official Gmail MCP server when your project is in the Workspace Developer Preview Program. That server lives at https://gmailmcp.googleapis.com/mcp/v1. It searches mail and creates drafts with create_draft; you open Gmail and send the draft yourself. This step uses a local Gmail MCP server so you can both create a draft and send a message with the same Google Cloud OAuth file from the Gmail lab. It runs with npx.

We will use @gongrzhe/server-gmail-autoauth-mcp. It talks to the Gmail API. You will not write SMTP code.

This server can send real email.
The second demo in this step sends a message from your Gmail account. Set the recipient to your own address. Do not point the agent at someone else's inbox, and do not ask it to delete mail. The package also exposes delete_email; leave that alone.

Part A — Install Node.js (required for the Gmail MCP server)

This Gmail server is an npm package, so you need Node.js (v18 or later) on your machine.

  1. Open nodejs.org in your browser and download the LTS installer for Windows.
  2. Run the installer and accept all defaults — make sure "Add to PATH" is ticked.

What is npx?
npx ships with Node.js. It runs an npm package on demand without installing it globally. The -y flag skips the confirmation prompt, which you need when Python launches the MCP server for you.

If sign-in says redirect_uri_mismatch.
This server finishes OAuth at http://localhost:3000/oauth2callback. A Desktop client usually accepts that. Part B2 — Put the key file where the server looks

The server reads gcp-oauth.keys.json from your user folder, under .gmail-mcp. Copy the file you just downloaded (or the one from the Gmail lab): 

# Windows Command Prompt
mkdir %USERPROFILE%\.gmail-mcp
copy credentials.json %USERPROFILE%\.gmail-mcp\gcp-oauth.keys.json

# Windows PowerShell
New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.gmail-mcp"
Copy-Item .\credentials.json "$env:USERPROFILE\.gmail-mcp\gcp-oauth.keys.json"
Keep that file secret. It is an OAuth client for your Google project. Do not commit credentials.json, gcp-oauth.keys.json, or the token the next command writes. Treat them the way you treat a password.

Part B3 — Sign in once

Run the auth command. A browser window opens. Sign in with the Gmail account you added as a test user and allow the requested access. The server saves a token as %USERPROFILE%\.gmail-mcp\credentials.json. You only do this once.

When it finishes, you should see a success message and the browser can be closed. Later runs reuse the saved token and refresh it when it expires.

Part C — Gmail MCP tools you will use

The package exposes many Gmail tools. For this lab, stay with draft and send. You will call them in natural language. The agent receives them with a gmail_ prefix, because that is the name of the server in the config below.

  • draft_email — create a draft. Arguments include to (a list of addresses), subject, and body. Nothing is sent.
  • send_email — send immediately, with the same to, subject, and body arguments.
  • search_emails — search with Gmail query syntax, for example from:me newer_than:1d.
  • read_email — read one message by its id.
  • list_email_labels — list labels such as INBOX and DRAFT.

Optional fields on draft and send include cc, bcc, htmlBody, and mimeType (text/plain, text/html, or multipart/alternative).

Official server, when you have preview access.

Open Gmail and send the draft yourself. Setup for that hosted server is in Google's configure the Gmail MCP server guide. The Python agent below uses the local npx server, which can draft and send with the credentials from this step.

Part D — Gmail demo agent — 11-GmailAgent.py

Save the script below as 11-GmailAgent.py. Change MY_EMAIL to your own Gmail address before you run it. The first prompt creates a draft. The second sends a short message to that same address. 

import asyncio
from pathlib import Path

from dotenv import load_dotenv
from langchain.agents import create_agent
from langchain.mcp import MCPAdapter

load_dotenv(Path(__file__).parent / ".env")

# Send only to yourself in this lab.
MY_EMAIL = "you@gmail.com"

DEMOS = [
    (
        "Create a draft",
        f"Create a Gmail draft, do not send it. "
        f"To: {MY_EMAIL}. "
        f"Subject: MCP draft test. "
        f"Body: This draft was created by my LangChain agent through the Gmail MCP server. "
        f"After the draft exists, tell me it was created and was not sent.",
    ),
    (
        "Send an email",
        f"Send an email now. "
        f"To: {MY_EMAIL}. "
        f"Subject: MCP send test. "
        f"Body: This message was sent by my LangChain agent through the Gmail MCP server. "
        f"After it is sent, tell me it was sent.",
    ),
]


async def main():
    config = {
        "mcpServers": {
            "gmail": {
                "command": "npx",
                "args": ["-y", "@gongrzhe/server-gmail-autoauth-mcp"],
            },
        }
    }

    async with MCPAdapter(config) as adapter:
        tools = await adapter.list_tools()
        print(f"Gmail MCP tools loaded ({len(tools)}): {[t.name for t in tools]}\n")

        agent = create_agent("openai:gpt-4o-mini", tools)

        for title, prompt in DEMOS:
            print("=" * 70)
            print(title)
            print("=" * 70)
            result = await agent.ainvoke(
                {"messages": [{"role": "user", "content": prompt}]}
            )
            print(result["messages"][-1].content)
            print()


if __name__ == "__main__":
    asyncio.run(main())
