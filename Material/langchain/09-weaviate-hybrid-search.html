Weaviate Hybrid Search – Hands-on Lab

How to use this lab
  1. Complete the install steps in Section 2 before writing notebook code.
  2. Create a notebook named 09-weaviate-hybrid-search.ipynb next to hybrid-search-docs/.
  3. For every Your Task, paste the code into a new cell and run it.
  4. Goal: use one Weaviate database for keyword (BM25) + similarity search — no separate in-memory BM25Retriever.

1. Why Weaviate?

In 09-hybrid-search.html you combined Chroma (vectors) with an in-memory BM25 retriever. That works for small labs, but production needs a database that stores both keyword and vector indexes persistently.

Weaviate (open source, BSD-3) does exactly that:

  • BM25 keyword search over text properties
  • Vector similarity over embeddings
  • Hybrid search that fuses both with an alpha weight

One DB, two indexes, fused at query time with alpha.

alpha Meaning
0.0 Pure keyword / BM25
0.5 Balanced hybrid (typical starting point)
1.0 Pure vector / similarity
LangChain’s WeaviateVectorStore.similarity_search(...) uses Weaviate’s hybrid operator under the hood. You control the blend with alpha.

2. Installation (do this first)

2.1 Prerequisites

  1. Docker Desktop installed and running (whale icon in the system tray on Windows).
  2. Python 3.10+ with pip.
  3. OPENAI_API_KEY in a .env file (same as earlier LangChain labs).
  4. The folder hybrid-search-docs/ from the previous hybrid lab (same SKU demo files).
Common failure: If Docker Desktop is not started, docker compose up fails with “failed to connect to the docker API” / “dockerDesktopLinuxEngine”. Start Docker Desktop, wait until it says “Engine running”, then retry.

2.2 Install Python packages

Your Task

In a terminal, run:

pip install -U langchain-weaviate weaviate-client langchain-openai langchain-community python-dotenv

2.3 Start Weaviate with Docker Compose

A compose file is provided next to this HTML: docker-compose.weaviate.yml. It exposes HTTP on port 8080 and gRPC on 50051, with a named volume for persistence.

Your Task

Open a terminal in the 02-langchain/htmls folder (where this HTML and the compose file live), then start Weaviate: 

cd 02-langchain/htmls
docker compose -f docker-compose.weaviate.yml up -d

Wait ~10–30 seconds for the container to become ready, then check:

docker compose -f docker-compose.weaviate.yml ps
curl http://localhost:8080/v1/.well-known/ready

On Windows PowerShell, if curl is awkward, open http://localhost:8080/v1/.well-known/ready in a browser — you should see a successful response when Weaviate is up.

Useful Docker commands
  • Logs: docker compose -f docker-compose.weaviate.yml logs -f weaviate
  • Stop (keep data): docker compose -f docker-compose.weaviate.yml down
  • Stop and delete volume (wipe DB): docker compose -f docker-compose.weaviate.yml down -v

2.4 One-line alternative (no compose file)

If you prefer a single command (data is less convenient to persist):

docker run -d --name weaviate-lab -p 8080:8080 -p 50051:50051 ^
  -e AUTHENTICATION_ANONYMOUS_ACCESS_ENABLED=true ^
  -e PERSISTENCE_DATA_PATH=/var/lib/weaviate ^
  -e CLUSTER_HOSTNAME=node1 ^
  semitechnologies/weaviate:1.27.0

(On PowerShell use backticks ` instead of ^ for line continuation, or paste as one line.)

4. Step 2 – Connect to Weaviate

The Python client v4 helper connect_to_local() talks to localhost:8080 (HTTP) and localhost:50051 (gRPC).

Your Task

Create a new cell and run:

import weaviate

client = weaviate.connect_to_local()
print("Weaviate ready:", client.is_ready())
print("Client version:", weaviate.__version__)
If is_ready() is False or you get a connection error, go back to Section 2.3 — Weaviate is not running yet.

5. Step 3 – Index Documents (Vectors Persist in Weaviate)

LangChain embeds each document with OpenAI and stores text + vectors in Weaviate. Weaviate also builds a BM25 index over the text automatically — you do not call BM25Retriever.from_documents.

Your Task

Create a new cell and run:

from langchain_openai import OpenAIEmbeddings
from langchain_weaviate.vectorstores import WeaviateVectorStore

embeddings = OpenAIEmbeddings(model="text-embedding-3-small")
collection_name = "HybridLabDocs"

if client.collections.exists(collection_name):
    client.collections.delete(collection_name)
    print(f"Deleted existing collection: {collection_name}")

vector_store = WeaviateVectorStore.from_documents(
    documents=docs,
    embedding=embeddings,
    client=client,
    index_name=collection_name,
    text_key="text",
)

print(f"✅ Indexed {len(docs)} documents into '{collection_name}'")
Restart your notebook later and you can reconnect with WeaviateVectorStore(client=client, index_name="HybridLabDocs", text_key="text", embedding=embeddings) without re-embedding — data lives in the Docker volume.

6. Step 4 – Pure Vector Search Is Not Enough

Use the same SKU trap as the previous lab. With alpha=1.0 (pure vector), Weaviate behaves like similarity-only search.

Your Task

Create a new cell and run:

from pathlib import Path

QUERY = "What is the warranty period for SKU-ZX9001?"
GOLD = "sku_zx9001_warranty.txt"

def source_name(doc):
    src = doc.metadata.get("source", "")
    return Path(src).name if src else str(doc.metadata)

top1 = vector_store.similarity_search(QUERY, k=1, alpha=1.0)[0]
print("Vector top-1 (alpha=1.0):", source_name(top1))
print(top1.page_content[:200])

if source_name(top1) != GOLD:
    print("❌ Wrong doc — often the 12-month general policy.")
else:
    print("⚠️ Gold ranked first this run — still compare with keyword/hybrid below.")

7. Step 5 – Pure Keyword (BM25) via Weaviate

alpha=0.0 asks Weaviate for BM25-only ranking — still served from the same database.

Your Task

Create a new cell and run:

top1 = vector_store.similarity_search(QUERY, k=1, alpha=0.0)[0]
print("BM25 top-1 (alpha=0.0):", source_name(top1))
print(top1.page_content[:200])

if source_name(top1) == GOLD:
    print("✅ BM25 inside Weaviate found the SKU bulletin.")
else:
    print("Unexpected — confirm hybrid-search-docs/ content.")

8. Step 6 – Hybrid Search (Production Style)

alpha=0.5 balances keyword and vector scores inside Weaviate. For ID-heavy queries you can bias toward keywords (e.g. alpha=0.3).

Your Task

Create a new cell and run:

top1 = vector_store.similarity_search(QUERY, k=1, alpha=0.5)[0]
print("Hybrid top-1 (alpha=0.5):", source_name(top1))
print(top1.page_content[:200])

if source_name(top1) == GOLD:
    print("✅ Hybrid recovered the correct SKU-ZX9001 document.")
else:
    print("Try alpha=0.3 (more keyword) if gold is not first.")

9. Step 7 – Side-by-Side Comparison

Your Task

Create a new cell and run:

def top1_name(alpha):
    return source_name(vector_store.similarity_search(QUERY, k=1, alpha=alpha)[0])

print("Query:", QUERY)
print("Vector  (alpha=1.0):", top1_name(1.0))
print("BM25    (alpha=0.0):", top1_name(0.0))
print("Hybrid  (alpha=0.5):", top1_name(0.5))
print("Gold:", GOLD)
