This guide walks you step by step through using the OpenAI Python client to send prompts, maintain conversation history, and finally build a simple chatbot UI with Gradio. You should actively type or copy each code block into your own Jupyter notebook and execute it.

How to use this guide
  1. Open Jupyter (Jupyter Notebook or JupyterLab) on your machine.
  2. Create a new notebook, for example: 01-using-openai-chatbot.ipynb.
  3. Place this HTML guide side-by-side with your notebook (split screen or a second monitor).
  4. Whenever you see a section that says “In your Jupyter notebook, create a new code cell…”, add a new code cell, then copy or type the code and run it.
  5. Carefully read the explanation around each code block and observe the outputs in your notebook as you go.

2. Calling the Chat Completions API

Next, we will send a minimal request from Python: a system message (optional behavior instructions) and a single user message. Running this shows how the messages list is structured and what the API returns. Later you will extend this to full back-and-forth conversations.

2.1 Call the Chat Completions API from Python

Your Task

In your Jupyter notebook, create a new code cell, copy or type the following code, and then execute the cell. Make sure you have already run the environment setup cells above. 

from openai import OpenAI
client = OpenAI()

response = client.chat.completions.create(
  model="gpt-4.1-mini",
  messages=[
    {
      "role": "system",
      "content": "Give your responses in a funny way . Limit your responses to atmost 3 sentences"
    },
    {
      "role": "user",
      "content": "Who is elon musk?"
    }
  ],
)
response

When you run this cell, you should see a full response object. Next, we will extract the text of the assistant's reply.

Your Task

In your Jupyter notebook, create a new code cell, copy or type the following line, and then execute the cell to print the assistant's message. 

response.choices[0].message.content

3. Helper Function for Chat Completions

It is convenient to wrap the chat completions call in a helper function that takes a list of messages and returns the assistant's reply text. We will define such a function next.

Your Task

In your Jupyter notebook, create a new code cell, copy or type the following function definition, and then execute the cell. 

def get_completion_from_messages(messages, model="gpt-4.1-mini", temperature=0):
    response = client.chat.completions.create(
        model=model,
        messages=messages,
        temperature=temperature, # this is the degree of randomness of the model's output
    )
    # print(str(response.choices[0].message))
    return response.choices[0].message.content

4. Maintaining Conversation State with a Message List

You can keep track of a conversation by maintaining a Python list of messages and passing it to the helper function. Each new user message is appended to the list before calling the model.

Your Task

In your Jupyter notebook, create a new code cell, copy or type the following code, and then execute the cell. Observe how the model remembers your name. 

messages =[]

messages.append({'role':'user', 'content': "My Name is SivaPrasad"})

get_completion_from_messages(messages)

messages.append({'role':'user', 'content': "What is my name"})

get_completion_from_messages(messages)

You should see that the second response correctly remembers the name from the first message, demonstrating how conversation history works.

Your Task

5. Building a Simple Chatbot UI with Gradio

Finally, we will wrap our model calls inside a simple web-based chat interface using the gradio library. This allows you (and your users) to chat with the model through a browser.

5.1 Install Gradio

Your Task

In your Jupyter notebook, create a new code cell, copy or type the following command, and then execute the cell to install Gradio. 

pip install gradio

5.2 Create the Gradio Chat Interface

We will define a predict function that converts the Gradio chat history into the message format expected by our get_completion_from_messages helper, and then use gr.ChatInterface to launch the UI.

Your Task

In your Jupyter notebook, create a new code cell, copy or type the following code, and then execute the cell. This will launch a Gradio chatbot in a new tab or inline (depending on your environment). 

import gradio as gr

def predict(message,history):

    print("Message:", message)
    print("History:", history)

    messages = []

    for history_item in history:
        messages.append(history_item)

    messages.append({ "role": "user", "content": message   })



    return get_completion_from_messages(messages)


gr.ChatInterface(predict).launch(debug=True)

Once the interface is running, type a few prompts and observe how the chatbot responds. When you are done, stop the Gradio server (for example, by interrupting the kernel in Jupyter).
