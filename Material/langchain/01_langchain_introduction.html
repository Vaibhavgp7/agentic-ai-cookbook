3. Creating LLMs in LangChain 1.0

LangChain 1.0 lets you initialize chat models in more than one way. First you will see the traditional pattern, and then the new unified initialization API.

3.1 Method 1 – Traditional Approach (Similar to 0.x)

Your Task

Create a new cell in your notebook, paste or type the following code, and execute the cell to create a traditional ChatOpenAI instance.

from langchain_openai import ChatOpenAI

# Create an LLM instance - traditional way
llm_traditional = ChatOpenAI(
    model="gpt-5-nano",
    temperature=0.7,
    max_tokens=100
)

3.2 Method 2 – New Unified Initialization (LangChain 1.0 Feature)

LangChain 1.0 introduces init_chat_model() for unified model initialization across different providers (OpenAI, Azure OpenAI, others). This makes it easier to swap providers without changing your code.

Your Task

Create a new cell in your notebook, paste or type the following code, and execute the cell to create an LLM using the unified initialization API.

from langchain.chat_models import init_chat_model

# Create LLM using the new unified initialization method
llm_unified = init_chat_model(
    model="gpt-4.1-mini",
    model_provider="openai",
    temperature=0.7,
    max_tokens=100
)

5. LCEL and the Runnable Interface

LangChain 1.0 is built around LCEL (LangChain Expression Language). Almost everything implements the Runnable interface, which exposes a consistent set of methods: invoke(), ainvoke(), batch(), and stream().

5.1 Streaming Responses

Streaming lets you handle partial outputs as they are generated, which is ideal for chat interfaces and long‑running responses.

Your Task

Create a new cell in your notebook, paste or type the following code, and execute the cell to stream a response from the model and print each chunk as it arrives.

# Stream the response for real-time output
print("🔄 Streaming response:")
print("-" * 50)

stream = llm_unified.stream([
    SystemMessage(content="You are a concise technical writer."),
    HumanMessage(content="Write a brief summary of what makes LangChain 1.0 special.")
])

for chunk in stream:
    print(chunk.content, end="", flush=True)

print("\n" + "-" * 50)
print("✅ Streaming complete!")

5.2 Batch Processing

With batch(), you can send many inputs at once and process the results efficiently. This is useful for generating multiple explanations or answers in parallel.

Your Task

Create a new cell in your notebook, paste or type the following code, and execute the cell to prepare multiple prompts and call batch() to process them together.

# Prepare multiple inputs for batch processing
batch_inputs = [
    "Why do parrots have colorful feathers?",
    "How do airplanes fly?",
    "What is quantum computing?"
]

# Process in batch
batch_results = llm_unified.batch(batch_inputs, config={
        'max_concurrency': 5
    })

print("📦 Batch Processing Results:")
print("=" * 60)
for i, result in enumerate(batch_results, 1):
    print(f"\n{i}. {result.content}...")
    print("-" * 40)

6. Output Parsing in LangChain 1.0

Output parsers help you turn raw LLM text into Python objects such as strings, dictionaries, and Pydantic models. This makes it much easier to build reliable downstream logic.

6.1 JSON Output Parser

Your Task

Create a new cell in your notebook, paste or type the following code, and execute the cell to ask the model for JSON output and parse it using JsonOutputParser.

from langchain_core.output_parsers import StrOutputParser, JsonOutputParser

# Create a JSON parser
parser = JsonOutputParser()

# Get a JSON-style response from the model
response = llm_unified.invoke([
    HumanMessage(content="""Tell me about elon musk, history, education, 
                 work experience, skills and achievements. Give the response in json format.""")
])

parsed_output = parser.invoke(response)

print("📝 Raw Output:" , response.content)
print(f"Raw response type: {type(response)}")
print(f"Parsed output type: {type(parsed_output)}")
print(f"Parsed content: {parsed_output}")

7. Building Chains with LCEL

LCEL uses the pipe operator (|) to chain components together. This lets you define clear data flows from prompts, through LLMs, into parsers and other logic.

7.1 Simple Chain – LLM + JSON Parser

Your Task

Create a new cell in your notebook, paste or type the following code, and execute the cell to create a simple chain that calls the LLM and then parses its JSON output.

# Create a simple chain: LLM + JSON Parser
simple_chain = llm_unified | JsonOutputParser()

# Test the chain
result = simple_chain.invoke([
    HumanMessage(content="""Tell me about elon musk, history, education, 
                 work experience, skills and achievements. Give the response in json format.""")
])

print(f"Chain result type: {type(result)}")
print(f"Chain result: {result}")

8. Prompt Templates in LangChain 1.0

Prompt templates let you parameterize messages with variables so you can reuse the same structure for many inputs.

8.1 Creating and Using ChatPromptTemplate

Your Task

Create a new cell in your notebook, paste or type the following code, and execute the cell to create a chat prompt template, format it, and inspect the resulting messages.

from langchain_core.prompts import ChatPromptTemplate

# Create a prompt template
prompt_template = ChatPromptTemplate.from_messages([
    ("system", "You are an expert in {subject}. Provide clear, concise explanations."),
    ("human", "Explain {topic} in simple terms.")
])

# Format the prompt
formatted_prompt = prompt_template.invoke({
    "subject": "software development", 
    "topic": "the differences between LangChain 0.x and 1.0"
})

print("📋 Formatted Prompt:")
for message in formatted_prompt.messages:
    print(f"{message.__class__.__name__}: {message.content}")

9. Structured Data with Pydantic Output Parser

Pydantic models let you specify a strict schema for the data you expect from the model. The PydanticOutputParser uses these models to parse structured responses safely.

9.1 Defining Pydantic Models and Format Instructions

Your Task

Create a new cell in your notebook, paste or type the following code, and execute the cell to define Pydantic models for people data and print the format instructions for the parser.

from typing import List
from langchain_core.output_parsers import PydanticOutputParser
from pydantic import BaseModel, Field


# Define data models using Pydantic
class Person(BaseModel):
    """Information about a person."""
    name: str = Field(description="The name of the person")
    height_in_meters: float = Field(description="The height of the person expressed in meters.")

class People(BaseModel):
    """Identifying information about all people in a text."""
    people: List[Person]

# Set up a Pydantic parser
pydantic_parser = PydanticOutputParser(pydantic_object=People)

print("📋 Pydantic Parser Format Instructions:")
print(pydantic_parser.get_format_instructions())

9.2 Using Pydantic Parser with ChatPromptTemplate

Your Task

Create a new cell in your notebook, paste or type the following code, and execute the cell to create a prompt with format instructions, call the chain, and then parse the model output into Pydantic objects.

# Create prompt with format instructions
structured_prompt = ChatPromptTemplate.from_messages([
    ("system", "Answer the user query. Wrap the output in `json` tags\n{format_instructions}"),
    ("human", "{query}")
]).partial(format_instructions=pydantic_parser.get_format_instructions())

# Create chain with Pydantic parser
structured_chain = structured_prompt | llm_unified

# Test the structured output
query = "Siva is 44 years old and 1.7 meters tall. Rishik is 15 years old and 1.8 meters tall."
result = structured_chain.invoke({"query": query})

print("🔗 Structured Chain Result:")
print(f"Type: {type(result).__name__}")
print(f"Content: {result.content}")


parsed_people = pydantic_parser.invoke(result)
print(f"\n✅ Parsed People: {parsed_people}")
print(f"People type: {type(parsed_people)}")
print(f"First person: {parsed_people.people[0].name} - {parsed_people.people[0].height_in_meters}m")
