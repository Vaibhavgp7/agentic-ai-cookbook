1. Why Hybrid Search?

In the RAG lab you used similarity search (dense embeddings). It follows meaning, so a paraphrase can still hit the right page. It can miss a page whose only distinctive clue is a rare exact token such as a SKU, error code, or part number.

BM25 does the opposite. It scores overlapping words. It finds SKU-ZX9001 even when the page never says “warranty”, and it misses a page that answers the question with different words (“annual leave” instead of “vacation”).

Hybrid search runs both and fuses the ranked lists. This lab uses two queries so you can see each method fail on its own:

  • Exact-token query – BM25 returns the SKU ledger. Similarity returns the generic 12‑month coverage page.
  • Paraphrase query – similarity returns the annual‑leave chapter. BM25 returns a party note that merely contains the words “vacation”, “employee”, and “holiday”.

Hybrid = keyword recall + semantic ranking, fused by an ensemble retriever.

Retriever Strengths Weaknesses
Similarity (dense) Meaning, synonyms, paraphrases Can bury rare IDs behind topical distractors
BM25 (sparse) Exact keywords, SKUs, error codes Misses paraphrases / synonyms
Hybrid (both) Best of both for production RAG Slightly more setup; need to tune weights

Use the prepared folder hybrid-search-docs/ (next to this HTML). The wording is deliberate: the right page for each demo query does not reuse the query’s distinctive words, and a distractor does.

  • aurora_pro_warranty.txt – Aurora Pro has a 24‑month plan (another coverage page).
  • annual_leave_policy.txt – staff accrue 15 days of annual leave. This page never says “vacation”, “employee”, or “holiday”.
  • holiday_party.txt – a facilities note. It does say “employees”, “vacation”, and “holiday”, but only about a party. It states no leave allowance.
  • wellness_room.txt – nap room and yoga. Related to rest, not an allowance.
  • returns_and_exchanges.txt – refunds, not coverage or leave.
  • error_code_7742.txt – an incident code. It is not an answer to either demo query.

Why hybrid is required
Neither retriever is top‑1 on both queries. A RAG app that trusts similarity alone answers 12 months for SKU‑ZX9001. A RAG app that trusts keywords alone describes a holiday party instead of the 15‑day annual‑leave allowance. Hybrid search returns the right document for both.

docs = DirectoryLoader(
    "hybrid-search-docs",
    glob="*.txt",
    loader_cls=TextLoader,
    loader_kwargs={"encoding": "utf-8"},
).load()

print(f"Loaded {len(docs)} documents")
for d in docs:
    print("-", Path(d.metadata["source"]).name)

5. Step 2 – Build a Similarity (Dense) Retriever

Embed the documents with OpenAI and store them in Chroma. This is the same style of retriever you used in the RAG lab.

Your Task

Create a new cell, paste and run:

from langchain_openai import OpenAIEmbeddings
from langchain_community.vectorstores import Chroma

vector_store = Chroma.from_documents(
    documents=docs,
    embedding=OpenAIEmbeddings(model="text-embedding-3-small"),
    collection_name="hybrid_lab",
)

# k=3, not 1. Hybrid fusion needs a short list from each retriever.
# With k=1 the two lists often hold different documents and the ranks tie.
similarity_retriever = vector_store.as_retriever(search_kwargs={"k": 3})
print("✅ Similarity retriever ready (k=3)")

6. Step 3 – Similarity Misses the SKU, Finds the Paraphrase

Run both demo queries. Similarity search should miss the SKU ledger (it follows “coverage length” and returns the 12‑month page) and hit the annual‑leave chapter (it understands “vacation” ≈ “annual leave”).

Your Task

Create a new cell, paste and run.

from pathlib import Path

SKU_QUERY = "What is the warranty period for SKU-ZX9001?"
SKU_GOLD = "sku_zx9001_warranty.txt"

LEAVE_QUERY = "How many vacation days can an employee take for a holiday?"
LEAVE_GOLD = "annual_leave_policy.txt"

def source_name(doc):
    return Path(doc.metadata["source"]).name

def show(title, query, hits):
    print("\n" + title)
    print("Query:", query)
    for i, doc in enumerate(hits, 1):
        print(f"  {i}. {source_name(doc)}")

show("SIMILARITY — exact token", SKU_QUERY, similarity_retriever.invoke(SKU_QUERY))
sku_top = source_name(similarity_retriever.invoke(SKU_QUERY)[0])
if sku_top != SKU_GOLD:
    print("❌ Similarity did not return the SKU ledger. Top-1 is the 12-month coverage page.")
else:
    print("⚠️ Unexpected — similarity ranked the SKU ledger first.")

show("SIMILARITY — paraphrase", LEAVE_QUERY, similarity_retriever.invoke(LEAVE_QUERY))
leave_top = source_name(similarity_retriever.invoke(LEAVE_QUERY)[0])
if leave_top == LEAVE_GOLD:
    print("✅ Similarity found annual leave from the words vacation / employee / holiday.")
else:
    print("❌ Unexpected top-1:", leave_top)
What you should observe
  • SKU query top‑1: general_warranty_policy.txt (12 months), not the 36‑month ledger.
  • Leave query top‑1: annual_leave_policy.txt (15 days of annual leave).

7. Step 4 – BM25 Finds the SKU, Misses the Paraphrase

BM25 scores overlapping terms. The tokenizer keeps sku-zx9001 as one token. On the leave question, the party note wins because it literally contains “employee”, “vacation”, and “holiday”, while the leave chapter uses “staff”, “annual leave”, and “absence”.

Your Task

Create a new cell, paste and run.

import re
from langchain_community.retrievers import BM25Retriever

def tokenize(text: str) -> list[str]:
    """Keep hyphenated IDs like sku-zx9001 intact."""
    return re.findall(r"[a-z0-9]+(?:-[a-z0-9]+)*", text.lower())

bm25_retriever = BM25Retriever.from_documents(docs, preprocess_func=tokenize)
bm25_retriever.k = 3

show("BM25 — exact token", SKU_QUERY, bm25_retriever.invoke(SKU_QUERY))
if source_name(bm25_retriever.invoke(SKU_QUERY)[0]) == SKU_GOLD:
    print("✅ BM25 returned the SKU ledger. Keyword search finds SKU-ZX9001.")
else:
    print("❌ Unexpected — check hybrid-search-docs/.")

show("BM25 — paraphrase", LEAVE_QUERY, bm25_retriever.invoke(LEAVE_QUERY))
bm25_leave_top = source_name(bm25_retriever.invoke(LEAVE_QUERY)[0])
if bm25_leave_top != LEAVE_GOLD:
    print("❌ BM25 did not return the leave policy. Top-1 is the holiday party note.")
else:
    print("⚠️ Unexpected — BM25 ranked annual leave first.")

8. Step 5 – Hybrid Search Recovers Both

LangChain’s EnsembleRetriever fuses the two lists with reciprocal rank fusion. A document that is rank 1 in one list and still present in the other list rises above a document that only won the weak retriever.

Your Task

Create a new cell, paste and run.

from langchain_classic.retrievers import EnsembleRetriever

hybrid_retriever = EnsembleRetriever(
    retrievers=[bm25_retriever, similarity_retriever],
    weights=[0.5, 0.5],
)

show("HYBRID — exact token", SKU_QUERY, hybrid_retriever.invoke(SKU_QUERY))
show("HYBRID — paraphrase", LEAVE_QUERY, hybrid_retriever.invoke(LEAVE_QUERY))

sku_ok = source_name(hybrid_retriever.invoke(SKU_QUERY)[0]) == SKU_GOLD
leave_ok = source_name(hybrid_retriever.invoke(LEAVE_QUERY)[0]) == LEAVE_GOLD
print("✅ Hybrid recovered both gold documents." if sku_ok and leave_ok else "❌ Hybrid missed a gold document.")
Expected comparison
  • SKU query: similarity → 12‑month page; BM25 → 36‑month ledger; hybrid → 36‑month ledger.
  • Leave query: similarity → 15‑day annual leave; BM25 → holiday party; hybrid → 15‑day annual leave.

10. What You Learned

  • Similarity search answers the paraphrase (“vacation” → annual leave) and misses the rare token SKU-ZX9001.
  • BM25 returns a result only when the query words actually occur. It finds the SKU and misses the leave policy.
  • Hybrid search is required when a corpus has both kinds of questions. EnsembleRetriever fuses the two ranked lists.
  • Keep k at 3 (or more) so each list contains more than a single hit. With k=1 the ranks often tie and the keyword miss can survive fusion.
